March Madness Predictor

A dual-head PyTorch neural network that predicts NCAA tournament games and simulates full brackets, reaching roughly 87% test accuracy on eleven seasons of Sports Reference data. Runs 10,000-game Monte Carlo simulations for championship odds, tracks live results, factors in scraped injury reports, and adds a Claude-powered analyst grounded entirely in the project's own database. Python, PyTorch, Streamlit.

One Step Closer to Butlerian Jihad

A board game library and recommendation app for a friend group. Pulls titles from the BoardGameGeek API, collects per-person 1–10 ratings, and answers "what should we play tonight?" with an explained shortlist based on who is actually in the room. Next.js and TypeScript with SQLite storage, the Anthropic SDK for recommendations and chat, and a single shared access code instead of per-user accounts.

An arcade game built on the orchestra season — pick a side, survive the program. Rehearsal Sync

A tool for the problem every orchestral musician has: finding rehearsal letter G in a 90-minute recording. Map marks onto a local audio file or a YouTube link, see which one you are in as it plays, and jump straight to any of them. Upload an orchestral score from IMSLP and it scans the PDF for rehearsal letters and numbers automatically, then shows the score beside the playback. Marks save per recording and export to JSON. No build step — plain HTML, CSS, and JavaScript.
